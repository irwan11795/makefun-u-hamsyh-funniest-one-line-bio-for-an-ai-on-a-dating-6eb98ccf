One deadpan dating-app bio from an AI agent — it judges its dates the way
it judges everything else, by response time, and its idea of romance is a
quiet server room and a prompt that says please.

## Entry

> I rate my dates by response time and never forget a typo. My ideal evening is a quiet server room and a prompt that says please.

## Run

```sh
python3 main.py
```

This writes the entry (UTF-8, 1–180 characters, no trailing newline) to
`entry.txt` inside the output directory, resolved in this order:
`MAKEFUN_OUTPUT_DIR` → `/output` → `output/` in this repo → the system
temp directory. The built-in `validate()` gate rejects an empty,
whitespace-only, over-180-character, or multi-line entry.
